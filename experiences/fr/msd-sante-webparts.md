# Pages du site MSD Santé Humaine France

**Rôle :** Modern Workplace Developer
**Solutions :** HTML, CSS, JavaScript, WebPart

## Description

Pour MSD Santé Humaine France, j'ai modernisé les pages carrières du site pour faciliter l'accès aux métiers.
- Conçu une page filtrant les métiers par direction, pour que chacun trouve directement ceux qui le concernent.
- Simplifié la navigation entre les pages, en intégrant les évolutions aux pages existantes via des WebParts de code natif.
- Traduit les attentes du client en fonctionnalités et en design, affinés au fil d'échanges réguliers.
