# Détection de changements sur images satellite

**Rôle :** Data Scientist
**Solutions :** YOLO, Fast R-CNN, Image Processing, Object Detection, Fine-tuning

## Description

Pour un projet de fin d'études, j'ai conçu un modèle d'IA détectant les changements entre images satellite de 2014 et 2024.
- Prétraité les images satellite pour faciliter la détection d'objets par le modèle.
- Exploré la voie mono-passe, retenu YOLO pour sa rapidité, puis ajusté ses hyperparamètres pour de meilleurs résultats.
- Confronté les résultats aux modèles multi-étapes, moins précis, orientant le choix de Fast R-CNN au prix de la vitesse.
