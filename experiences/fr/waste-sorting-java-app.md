# Application Java de tri des déchets

**Rôle :** Développeur Full Stack
**Solutions :** Java, StarUML, JavaFX, Scene Builder

## Description

Pour le projet en équipe concluant le cours de Java, j'ai conçu l'architecture back-end d'une application de tri des déchets en programmation orientée objet.
- Modélisé les classes, leurs attributs (poids, type, capacité) et leurs relations 1-1 et 1-N.
- Conçu les méthodes cœur des classes pour traiter chaque objet selon son type.
- Recherché puis intégré une solution de sérialisation pour conserver l'état des objets, à jour après chaque ajout ou vidage.
