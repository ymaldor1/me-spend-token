# DetteIT + DSSI : développement de WebPart

**Rôle :** Développeur SharePoint
**Solutions :** Azure DevOps, SPFx, Power Automate, Ingénierie agentique

## Description

**DetteIT :** Corrigé les bugs remontés par le client et amélioré le WebPart.
- Tranché les demandes ambiguës avec le client lors de réunions tout au long de la mission.
- Scripté le provisionnement et empaqueté la livraison.

**DSSI :** Piloté un agent IA pour construire un WebPart à partir des spécifications existantes.
- Comblé les manques de spec relevés par l'agent, puis creusé au-delà de son rendu propre pour repérer des fonctionnalités à moitié fonctionnelles et le réorienter.
- Conçu un flux Power Automate pour gérer les permissions par statut, le WebPart étant limité aux droits de l'utilisateur courant.
