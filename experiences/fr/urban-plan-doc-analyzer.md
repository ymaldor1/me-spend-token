# Analyseur de documents d'urbanisme

**Rôle :** Développeur
**Solutions :** Web Scraping, OCR, Regular Expressions, Python

## Description

J'ai automatisé l'analyse de gros PDF d'urbanisme, projet à six personnes, supprimant une relecture manuelle chronophage.
- Défini la stratégie de récupération de texte : extraction PDF native, OCR en repli.
- Recensé les formulations réglementaires dans une cinquantaine de documents pour bâtir une bibliothèque de regex réutilisable.
- Conçu le schéma JSON par zone d'aménagement, modélisant les règles (taille du toit, épaisseur des murs).
