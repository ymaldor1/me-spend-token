# DetteIT + DSSI WebPart Development

**Role:** SharePoint Developer
**Solutions:** Azure DevOps, SPFx, Power Automate, Agentic Engineering

## Description

**DetteIT:** Cleared client-reported bugs and improved the WebPart.
- Settled unclear requests with the client in meetings throughout the mission.
- Scripted provisioning and packaged the delivery.

**DSSI:** Steered an AI agent to build a WebPart from existing specs.
- Filled spec gaps the agent flagged, then probed past its clean output to catch half-working features and redirect it.
- Designed a Power Automate flow for status-driven item permissions, as the WebPart was limited to the current user's rights.
