# Automated SharePoint Provisioning for Document Management Sites

**Role:** Developer
**Solutions:** Azure Functions, Azure Logic Apps, Microsoft Forms, SharePoint, Microsoft Entra ID

## Description

Automated the entire SharePoint provisioning chain so document-management site requests went live without manual steps.
- Built the request form, the single entry point whose submission triggered the site's creation.
- Implemented the full provisioning: lists, archive libraries, groups and permissions, identical across every site.
- Developed a stats WebPart, added to each site's home page, to track storage and active or archived documents.
