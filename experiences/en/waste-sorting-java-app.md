# Java Waste-Sorting Application

**Role:** Full Stack Developer
**Solutions:** Java, StarUML, JavaFX, Scene Builder

## Description

Built a waste-sorting application, from data model to interface, as the final project of a Java course.
- Modeled classes, their attributes (weight, type, capacity) and 1-1 and 1-N relationships.
- Designed the core methods of classes to process each object according to its type.
- Researched and integrated a serialization solution to persist object state, kept up to date after each addition or emptying.
